# Bundled artwork

All existing portrait and picnic assets are unchanged from the verified Phase 1 project. The portraits represent fictional adults and were AI-generated for this prototype. They are not photographs of verified members. The picnic is shared sample inspiration, not a second authenticated photograph of each person.

No artwork was generated or fetched in Phase 1.5. The prefilled Alex demo profile now uses the existing `rowan` portrait asset so the mutual-match preview displays two portraits rather than a picnic. That sample portrait is intentionally reused by the Rowan fixture. A profile completed through onboarding uses the photo chosen there.

This recovered source copy did not include the earlier documentation bundle. The original image-generation prompts could not be recovered from the unavailable Documents workspace; they are not reconstructed or claimed here. The bundled source assets themselves were retained byte for byte.
