# Bundled artwork

All Phase 1 portrait and picnic assets are unchanged from the verified Phase 1 project. The portraits represent fictional adults and were AI-generated for this prototype. They are not photographs of verified members. The picnic is shared sample inspiration, not a second authenticated photograph of each person.

The prefilled Alex demo profile uses a dedicated generated portrait of a fictional adult man. A profile completed through onboarding uses the photo chosen there.

This recovered source copy did not include the earlier documentation bundle. The original image-generation prompts could not be recovered from the unavailable Documents workspace; they are not reconstructed or claimed here. The bundled source assets themselves were retained byte for byte.
